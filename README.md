# 胶片放映 · FilmAlbum

一个无依赖、纯静态的「胶片放映」网页。把一段段胶片素材模拟成老式放映机：影片**插入动画播到第 82 帧（2 秒 22 帧）定格**，按下方向键后继续播完**退出动画**，并无缝切到下一格——暗夜影院感的沉浸式浏览体验。

> 📦 本仓库只包含代码，**不含素材**。按下方「素材放置指南」放入自己的素材即可运行。

---

## ✨ 功能特性

| 特性 | 说明 |
| --- | --- |
| 🎞️ 82 帧定格 | 每格素材播放到第 82 帧（≈2.733s）自动定格，模拟胶片卡住 |
| 🔀 伪随机轮次 | Fisher-Yates 洗牌，每轮 N 格不重复，跨轮预生成 |
| ⚡ 双缓冲无缝切换 | 双 `<video>` 交替 + 方向感知预缓存，切换无黑屏 |
| 📶 连续切换 | 快速连按：中间素材直接从 82 帧起播（跳过插入动画），松手 250ms 后自动停止 |
| 🎛️ 底部控制区 | 上一格 / 背景音 / 下一格，**独立分区不叠视频**，浏览器劫持视频时按钮仍可点 |
| 🎨 极简电影感 UI | 毛玻璃胶囊控制岛、宋体衬线标题、投影灯光晕、影院暗角、胶片颗粒 |
| 🖥️ 多端操作 | 键盘 / 鼠标 / 触摸滑动 / 底部按钮四套交互 |

## 🚀 快速开始

```bash
# 1. 放置素材（见下方指南）
# 2. 本地预览（推荐用静态服务器，避免 file:// 限制）
cd FilmAlbum
npx serve .        # 或 python -m http.server 8000
# 3. 浏览器打开 http://localhost:8000
```

**部署**：任意静态托管（Nginx / 对象存储 / Vercel 等），上传代码文件 + 素材目录：

```
index.html
style.css
script.js
shucai/          # 素材目录（本地按指南生成后一起上传）
```

> ⚠️ 微信 / 腾讯 X5 内核缓存较顽固，更新后请在微信内强刷或清缓存。

## 📥 素材放置指南

素材目录 `shucai/` **不随代码分发**（已加入 `.gitignore`），按以下步骤放置：

```
FilmAlbum/
└── shucai/              ← 在项目根目录新建
    ├── maybe.mp3        ← 背景音乐（可选，缺省则无 BGM）
    └── sp1/             ← 第 1 格素材
    │   ├── s1.mp4       ← 影片（必须）
    │   └── p1.jpg       ← 封面图（可选，暂未使用）
    ├── sp2/
    │   ├── s2.mp4
    │   └── p2.jpg
    └── ... spN/
```

**步骤**：

1. 在项目根目录创建 `shucai/` 文件夹
2. 创建 `sp1` ~ `spN` 子目录，**命名必须连续**（`sp1, sp2, sp3...`，不能跳号）
3. 每个 `spN/` 内放入 `sN.mp4`（文件名与目录编号一致）
4. （可选）背景音乐命名为 `maybe.mp3` 放入 `shucai/`
5. 若增删素材数量，同步修改 `script.js` 顶部的 `SP_COUNT` 常量

**素材规格要求**：

| 项 | 要求 |
| --- | --- |
| 帧率 | 统一 **30fps** |
| 结构 | 前 **82 帧**为插入动画（0 → 2.733s），82 帧之后为退出动画 |
| 建议时长 | **≥ 3.0 秒**（不足 82 帧的素材会在片尾冻结而非定格，且无退出动画） |
| 画面 | 竖屏 1080×1440 为佳；显示时按 `object-fit: contain` 等比居中 |
| 音轨 | 素材可带音轨（未静音）；与背景音乐 `<audio>` 独立互不冲突 |

> 若只想快速测试：把任意 1 个视频复制成 3 份并改名为 `shucai/sp1/s1.mp4`、`sp2/s2.mp4`、`sp3/s3.mp4`，同时把 `SP_COUNT` 改成 `3` 即可。

## 🎮 操作指南

| 操作 | 效果 |
| --- | --- |
| 鼠标点击画面 / 空格 / → | 下一格 |
| ← | 上一格 |
| M | 静音 / 恢复背景音乐 |
| 移动端左滑 / 右滑 | 下一格 / 上一格 |
| 底部「◀」「▶」 | 上一格 / 下一格 |
| 底部「🔊」 | 背景音乐开关（静音态图标带斜线并降透明） |

> 连续按「下一格」会进入快速切换模式：跳过中间素材的插入动画，松手后约 0.25s 停止；轮次第一格时「上一格」按钮自动置灰。

## ⚙️ 可调参数（script.js 顶部）

| 常量 | 默认值 | 说明 |
| --- | --- | --- |
| `SP_COUNT` | `21` | 素材总数（与 shucai/spN 数量一致） |
| `TARGET_FRAME` | `82` | 定格帧号（2s22f @30fps） |
| `PRESS_GAP` | `250` | 距最后一次按键超过该毫秒数视为已松手，队列停止 |
| BGM 音量 | `0.5` | `beginScreening` 中 `bgm.volume` |

## 🧠 技术要点

- **状态机**：`BOOT → INSERT → PAUSED → RESUME → SWITCHING`，切换方向由 `pending` 队列管理
- **帧级定格**：优先 `requestVideoFrameCallback` 追帧到 82 帧暂停，不支持时降级为 rAF 轮询
- **连续切换队列**：按键入队，片尾消费；`PRESS_GAP` 判断「已松手」时清空剩余队列，杜绝「松手后自动走完」
- **防劫持**：`playsinline / webkit-playsinline / x5-video-player-type=h5-page / controlslist / disablepictureinpicture` 全属性声明 + `.film{pointer-events:none}` + 点击/滑动统一由 `#theater` 容器接管
- **底部控制区**：独立于视频区域的 flex 分区（非悬浮叠加），即使第三方内核劫持视频，按钮仍可正常操作
- **边界状态**：轮首时「上一格」置灰（`.disabled`），`syncControlState()` 随轮次实时同步

## 📝 注意事项

- 播放依赖用户手势（点击「开始放映」），符合浏览器自动播放策略
- 未放置素材时页面只有界面没有影片，属正常现象
- 本项目纯静态、零依赖、零构建，修改后直接刷新即可生效
